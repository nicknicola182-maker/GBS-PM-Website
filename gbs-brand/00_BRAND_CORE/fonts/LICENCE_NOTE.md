# Font files

Montserrat (Julieta Ulanovsky et al.) and Inter (Rasmus Andersson) are both licensed under the SIL Open Font License 1.1, which permits bundling in web, print and embroidery workflows without a separate purchase. Keep a copy of the OFL text with any files handed to suppliers.

- `*-latin.woff2`: web subset, referenced by `00_BRAND_CORE/fonts.css` and the website.
- `*.ttf`: full static instances used by the print renderer and the logo outlining script.
